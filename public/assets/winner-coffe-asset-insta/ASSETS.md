# Katalog Aset Website — Winner Cafe

Dokumen ini memuat katalog lengkap 65 gambar aset website untuk **Winner Cafe**, yang telah disortir, dibersihkan dari duplikasi, dan dinamai ulang (*renamed*) secara semantik untuk keperluan aset web, SEO, dan aksesibilitas.

---

## 📌 Konvensi Penamaan (*Naming Convention*)

Format nama file:  
`[suasana/setting]-[makanan/minuman]-[aktivitas]-[interaksi].jpg`

- **Format:** Huruf kecil (*lowercase*) dengan pemisah tanda hubung (*kebab-case* `-`).
- **Bahasa:** Bahasa Inggris (*standard web asset naming*).
- **Elemen:**
  1. **Atmosphere / Setting (Suasana):** Suasana ruang, pencahayaan, atau lokasi (misal: `cozy`, `night`, `bright`, `outdoor-balcony`, `modern-glasshouse`).
  2. **Food / Drink (Makanan/Minuman):** Jenis hidangan atau minuman yang tampil (misal: `hot-latte`, `chicken-katsu`, `dimsum-mentai`, `iced-coffee`).
  3. **Action / Activity (Aktivitas):** Apa yang sedang dilakukan (misal: `steaming-milk`, `pouring-latte-art`, `working-laptop`, `serving-food`).
  4. **Interaction (Interaksi):** Hubungan atau kontak antar subjek/objek (misal: `friends-hangout`, `ordering`, `mirror-selfie`, `hands-holding`).

## 💡 Panduan Penggunaan untuk Pengembang Website

1. **Optimalisasi Ukuran & Format:**  
   Untuk performa Core Web Vitals website yang maksimal, konversi file `.jpg` ini ke format modern **WebP** atau **AVIF** dengan kompresi kualitas 80–85%.
2. **Atribut `alt` Gambar (Accessibility & SEO):**  
   Gunakan deskripsi pada kolom *Aktivitas / Aksi* dan *Makanan / Minuman* sebagai atribut `alt=""` pada tag `<img>`.  
   *Contoh:* `<img src="barista-pouring-latte-art-coffee-bar.webp" alt="Barista menuangkan steamed milk membentuk latte art di cangkir keramik Winner Cafe">`
3. **Lazy Loading:**  
   Gunakan atribut `loading="lazy"` pada gambar di bawah layar (*below the fold*) seperti galeri foto menu dan fasilitas. Gambar *Hero Banner* gunakan `loading="eager"` atau `fetchpriority="high"`.
